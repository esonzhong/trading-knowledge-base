闪卡001 第一部分：风险与交易工具

交易的底层逻辑是什么？

答案

交易的底层逻辑是期望值（EV）框架： EV = 概率(P) × 盈亏比(R) - 成本(C) 每次下注 = 用有限风险（止损/权利金）去博"概率 × 盈亏比"这个乘积 只要 EV > 0，这笔交易就是数学上正确的。

闪卡002 第一部分：风险与交易工具

现货的风险本质是什么？

答案

现货的风险本质是方向性损失 + 止损纪律 最大损失 = 本金全部（若不止损） 核心变量：方向 + 止损纪律

闪卡003 第一部分：风险与交易工具

合约/永续的风险本质是什么？

答案

合约/永续的风险本质是杠杆放大损失 最大损失 = 本金全部 + 可能穿仓 核心变量：方向 + 杠杆倍数 + 止损纪律 穿仓原因：杠杆 + 强平机制 + 流动性断层三者叠加

闪卡004 第一部分：风险与交易工具

合约为什么会穿仓？

答案

核心原因是杠杆 + 强平机制 + 流动性断层三者叠加： 1. 仓位亏损 → 扣减保证金 2. 触及强平线 → 交易所强制平仓 3. 价格断层 → 实际成交价跳过强平价 插针是最常见的穿仓场景（暴跌时强平价下方无流动性，实际成交价远低于强平价）

闪卡005 第一部分：风险与交易工具

买期权（Call/Put买方）的风险本质是什么？

答案

买期权（Call/Put买方）的风险本质是权利金损失（有限风险） Call买方最大损失 = 已付权利金（价格归零也只亏这么多） Put买方最大损失 = 已付权利金 核心变量：时间价值衰减（Theta）

闪卡006 第一部分：风险与交易工具

卖期权（Short Call/Put卖方）的风险本质是什么？

答案

卖期权（Short Call/Put卖方）的风险本质是理论上无限的敞口风险 Short Put = 被行权需按约定价格接盘 + 保证金被追缴 Short Call = 被行权需按约定价格卖出 + 保证金被追缴 最大盈利 = 权利金，最大损失 = 理论无限（标的价格跌到0） 核心变量：方向 + 波动率 + 时间

闪卡007 第一部分：风险与交易工具

什么是"用风险去下注"？

答案

"用风险去下注"这句话的含义是：每次交易都是用有限风险（止损损失/权利金）去博"概率 × 盈亏比"这个乘积。只要EV为正，这笔交易就是数学上正确的。

不同交易工具的适用场景是什么？

答案

不同交易工具分别适合： • 现货：高概率 + 中等盈亏比（趋势跟踪） • 合约：中等概率 + 高盈亏比（PA精准入场） • 买期权：低概率 + 极高盈亏比（彩票策略） • 卖期权：高概率 + 低盈亏比（收割时间价值） 共同点：都是用"有限风险"换取"不确定但可计算的正期望"

结构概率的实际应用原则是什么？

答案

结构概率的实战应用原则： • 强趋势中：只顺势，只找回踩入场，不做逆势，不猜顶底 • 震荡中：高抛低吸，不追破位，不持有"梦想仓位" • 反转初期：开始轻仓试仓，止损要宽，不重仓追涨杀跌

信号概率回答"入场点是否在关键位置？"的问题，入场点越接近关键结构，胜率越高。

闪卡021 第二部分：概率三维度

信号概率的核心原则是什么？

答案

信号胜率 = 位置精确度 × K线确认强度 • 位置精确度：关键支撑压力区（1-2%以内）→ ✅；中段模糊区 → ❌ • K线确认强度：三重确认（pin bar + 缩量 + 背离）→ ✅✅✅；单根反转K → ✅；无确认直接入场 → ❌

什么是催化剂概率（Catalyst）？

答案

催化剂概率回答"有没有推动价格继续走的力量？"的问题，没有催化剂的信号容易失败。

答案

无催化剂 = 无消息、无数据、无明显逻辑，纯粹技术面"感觉" → 胜率打折，容易被短期波动洗出

闪卡027 第二部分：概率三维度

催化剂能否弥补结构和信号的缺陷？

答案

不能。催化剂只是加分项，上限一般1.15-1.20，不能弥补结构和信号的缺陷。三个维度都必须达标才有高胜率。

闪卡028 第二部分：概率三维度

三维度叠加的总胜率计算公式是什么？

答案

总胜率 ≈ 结构概率 × 信号概率 × 催化剂系数

闪卡029 第二部分：概率三维度

做单三问是什么？

答案

实战中做单三问： 1. 结构是什么？顺势还是逆势？（结构胜率） 2. 入场点在关键位吗？有K线确认吗？（信号胜率） 3. 有催化剂吗？数据？突破？放量？（催化剂加成） 满足前两条才考虑入场；满足三条 → 重仓/加仓；只满足一条 → 轻仓/不做；三条都不满足 → 绝对不做

强趋势顺势回踩入场的期望值分析

震荡区间高抛低吸的期望值分析

震荡区间高抛低吸： • 胜率：45-55% • 盈亏比：1:1~1.5:1 • 期望值：⚠️ 勉强 原因：上下轨之间距离有限，每次赚的可能就一点点，亏一次可能就回到原点

闪卡033 第三部分：场景详解

为什么震荡高抛低吸只是"勉强"正EV？

答案

胜率50%，盈亏比1:1 → 100次交易 = 50赢×1R - 50亏×1R = 0R（刚好白干）。必须做到胜率52%+ 且 盈亏比1.1:1才有微利，手续费一扣，可能还是负的。

楔形第3-4次突破： • 胜率：60-70% • 盈亏比：2:1~3:1 • 期望值：✅ 正 通俗理解：蓄力足够多，一旦突破，幅度通常是前面震荡区间的2-3倍。又准又狠 → 高胜率 + 高盈亏比 = 黄金机会

    为什么突破追涨胜率低？

    答案

    刚突破时，价格往往在最不稳定的位置，还没等来"回踩确认"，直接追的风险极大。就像球还没停稳你就伸手去接，大概率接空。

    闪卡038 第三部分：场景详解

    什么时候突破追涨胜率会提高？

    答案

    突破追涨胜率提高的情况： • 突破+放量+无重大阻力位 → 胜率可到50% • 非农/数据发布后顺势追 → 胜率可到55% • 突破整数关口（$100,000）→ 胜率提高 但仍不是最佳入场点，最佳点永远是：突破后的回踩确认点

    闪卡039 第三部分：场景详解

    逆势摸顶抄底的期望值分析

    答案

    逆势摸顶抄底： • 胜率：25-35% • 盈亏比：需>4:1才合算 • 期望值：❌ 负EV（长期必亏）

    闪卡040 第三部分：场景详解

    为什么逆势摸顶抄底胜率低？

    答案

    市场的顶和底是走出来之后才知道的，在走出来之前，所有摸顶抄底都是"赌"。趋势有惯性，逆势 = 和惯性对抗 → 大多数时候输。

    闪卡041 第三部分：场景详解

    Al Brooks对摸顶抄底的态度是什么？

    答案

    Al Brooks 明确说："Never try to pick the top or bottom"（永远不要去猜顶底）。顺势 → 等信号回调入场；逆势 → 等更确认的信号，做小止损。但本质上，逆势仍然是低胜率，Al Brooks 自己也不推荐。

    闪卡042 第三部分：场景详解

    期望值场景的总结是什么？

    答案

    高期望值场景（值得重仓）： • ✅ 强趋势 + 回踩入场 = 70% × 2R = 正EV • ✅ 楔形第3-4次突破 = 65% × 2.5R = 正EV 中等期望值场景（轻仓/小仓位）： • ⚠️ 震荡高抛低吸 = 50% × 1.2R ≈ 白干 • ⚠️ 突破追涨 = 35% × 2R ≈ 白干 负期望值场景（尽量避免）： • ❌ 逆势摸顶抄底 = 30% × 1.5R = 负EV • ❌ 无信号、无催化剂、无结构 = 25% × 1R = 负EV

    闪卡043 第四部分：趋势判断

    强趋势的"五字口诀"是什么？

    答案

    强趋势"五字口诀"：大、连、少、浅、快 • 大 = 实体K线大（多空一方主导） • 连 = 连续出现（一根接一根） • 少 = 重叠少（K线之间很少互相遮盖） • 浅 = 回调浅（1-3根K线就结束） • 快 = 远离快（突破后迅速拉开距离）

    闪卡044 第四部分：趋势判断

    强趋势的K线实体大小特征是什么？

    答案

    强上升趋势 = 大实体阳线，多头主导；弱上升趋势 = 小实体，多空拉扯。

    闪卡045 第四部分：趋势判断

    强趋势的连续性特征是什么？

    答案

    强趋势：连续5根以上同向K线，中间很少夹杂反向K；弱趋势：2-3根阳线后立刻出现阴线，反复拉锯。

    闪卡046 第四部分：趋势判断

    强趋势的重叠度特征是什么？（最关键的特征）

    答案

    强趋势：每根K线几乎不覆盖前一根，K线紧密排列，收盘逐级抬高；弱趋势：大量重叠，上下影线交错。

    闪卡047 第四部分：趋势判断

    强趋势的回调深度特征是什么？

    答案

    强上升趋势的回调：只回调1根K线，就继续上涨；弱上升趋势的回调：回调5根以上，深度超过50%。

    闪卡048 第四部分：趋势判断

    强趋势的收盘位置特征是什么？

    答案

    强上升趋势：收盘在当天最高点附近，多头完全主导；弱上升趋势：收盘在当天中间，多空还在博弈。

    闪卡049 第四部分：趋势判断

    强趋势突破后的表现特征是什么？

    答案

    强趋势突破：快速远离，突破后几乎没有回踩，直接涨；弱趋势突破：犹豫，突破后又回来，回踩很深的假突破。

    闪卡050 第四部分：趋势判断

    弱趋势的"五字口诀"是什么？

    答案

    弱趋势"五字口诀"：小、十、多、深、慢 • 小 = 实体K线小（多空博弈） • 十 = 十字星多（犹豫） • 多 = 重叠多（互相覆盖） • 深 = 回调深（5根以上） • 慢 = 远离慢（假突破多）

    闪卡051 第四部分：趋势判断

    强趋势vs弱趋势的对照表

    答案

  • 实体大小：强>60%实体 vs 弱<40%实体 • 连续性：强5根+同向 vs 弱2-3根就断 • 重叠度：强极少重叠 vs 弱大量重叠 • 回调深度：强1-3根K线（浅） vs 弱5根+K线（深） • 收盘位置：强极值（高/低） vs 弱中间 • 突破后表现：强快速远离 vs 弱犹豫回踩

    强趋势判断的3步流程是什么？

    答案

    第一步：看K线形态（5秒） 数最近10根K线：大实体阳线多 + 收盘在高位 → 强上升趋势；小实体/十字星多 + 收盘在中位 → 弱趋势 第二步：数回调深度（5秒） 1-3根止跌 → 强趋势；5根以上才止跌 → 弱趋势/震荡 第三步：看前低/前高（5秒） 强上升趋势：每次回调的低点不断抬高；弱上升趋势：低点降低 or 走平

    闪卡053 第四部分：趋势判断

    均线的量化标准是什么？

    答案

    均线多头排列（短期>中期>长期）→ 强上升趋势 均线缠绕/空头排列 → 弱趋势/震荡 EMA 20/50/200 三线收敛 → 震荡（无趋势）

    闪卡054 第四部分：趋势判断

    强趋势信号有哪些？（可以做，顺势重仓）

    答案

    强趋势信号： • 连续大实体K线，5根以上 • 重叠极少，收盘逐级抬高 • 回调1-3根K线就继续上涨 • 突破后不回踩，直接远离

    闪卡055 第四部分：趋势判断

    弱趋势信号有哪些？（轻仓或不做）

    答案

    弱趋势信号： • K线小、十字星多 • 重叠严重，收盘中位 • 回调5根以上 • 突破后反复回踩，假突破多

    闪卡056 第四部分：趋势判断

    禁止下单信号是什么？

    答案

    禁止下单信号：连弱趋势都算不上的混沌行情（高低点无规律，完全随机）

    闪卡057 第五部分：支撑测试

    趋势中的支撑测试次数越多会怎样？

    答案

    趋势中的支撑（均线/趋势线）测试次数越多，支撑作用越强。每次测试 = 多头在支撑位确认买入 → 共识越来越强 → 支撑越来越稳。

    闪卡058 第五部分：支撑测试

    震荡中的水平支撑测试次数越多会怎样？

    答案

    震荡中的水平支撑测试次数越多，支撑作用越弱。第4-5次测试后常出现突破大跌。

    闪卡059 第五部分：支撑测试

    趋势型支撑越测试越强的原因是什么？

    答案

    因为顺势方向，共识增强。每次测试都证明支撑有效，多头信心增强，空头不敢轻易挑战。

    闪卡060 第五部分：支撑测试

    水平支撑越测试越弱的物理学解释是什么？

    答案

    物理学解释 = 弹簧理论：每次测试"压下去"，都在消耗支撑位的"能量"。弹簧反复压缩 → 金属疲劳 → 最终断裂。

    闪卡061 第五部分：支撑测试

    水平支撑越测试越弱的博弈论解释是什么？

    答案

    博弈论解释： • 第1次：空头"试试"支撑力度，多头接住 • 第2次：空头加大力度，多头继续接 • 第3次：空头知道支撑稳了，提前布局空单 • 第4次：多头"习惯性"买入，但空头已经在那里等着砸 → 突破

    闪卡062 第五部分：支撑测试

    判断支撑still强的K线特征是什么？

    答案

    判断支撑仍然强的K线特征： • ✅ 止跌K线干净（pin bar / 吞没） • ✅ 反弹速度越来越快 • ✅ 反弹幅度大 • ✅ 成交量收缩（无需大量就能撑住）

    闪卡063 第五部分：支撑测试

    判断支撑在衰减的K线特征是什么？

    答案

    判断支撑在衰减的K线特征： • ⚠️ 止跌K线复杂（多次试探才稳住） • ⚠️ 反弹慢、幅度小 • ⚠️ 成交量放大（越来越需要更多钱才能撑住）

    闪卡064 第五部分：支撑测试

    判断支撑即将突破的特征是什么？

    答案

    判断支撑即将突破的特征： • ❌ 越来越难止跌 • ❌ 每次都创出新低（不是"守住"，是"刚好没破"） • ❌ 实体K线越来越小（多空都在撤退） • ❌ 突破前极度收敛（波动率压缩到极限）

    闪卡065 第五部分：支撑测试

    一句话总结支撑测试次数的影响

    答案

    趋势中的支撑（顺势）→ 越测试越强 → 回调入场；震荡中的支撑（逆势）→ 越测试越弱 → 第3次后警惕。

    闪卡066 第六部分：杠杆仓位

    风险相同的核心公式是什么？

    答案

    风险相同 = 止损距离（%）× 仓位大小（%）× 杠杆倍数 = 常数

    闪卡067 第六部分：杠杆仓位

    止损距离相同时，50x和1x的风险是否相同？

    答案

    相同。止损距离固定为5%时，无论1x还是50x，绝对亏损都是5元（本金5%）。

    闪卡068 第六部分：杠杆仓位

    杠杆真正节省的是什么？

    答案

    保证金占用 = 仓位名义值 / 杠杆倍数。杠杆节省的是保证金占用，让"闲置资金"可以释放出来。

    闪卡069 第六部分：杠杆仓位

    杠杆的合理用法——路径一的含义是什么？

    答案

    放大仓位（不放大风险）：用杠杆把保证金压缩到固定比例（如10%），用同样的100元能开10倍大的仓位，但容错空间极小，止损容易被扫掉。

    闪卡070 第六部分：杠杆仓位

    杠杆的合理用法——路径二的含义是什么？

    答案

    控制保证金 = 控制仓位数量：把保证金压缩后，剩余资金隔离/另用，但危险在于容易开过多仓位，累积起来全部本金暴露。

    闪卡071 第六部分：杠杆仓位

    杠杆错误用法的核心原因是什么？

    答案

    高杠杆"感觉"风险小 → 随意开仓 → 累积仓位 → 一次性爆。每次看起来"风险很小"，但累积起来全部本金都在暴露。

    闪卡072 第六部分：杠杆仓位

    合理杠杆的使用建议是什么？

    答案

    ✅ 合理杠杆的用法： 1. 先确定止损位（Al Brooks支撑/压力位） 2. 计算该止损位对应的仓位大小 3. 用杠杆压缩保证金，把"闲置资金"隔离 4. 永远不超过总仓位预算（如账户的20-30%） ❌ 杠杆的错误用法：用高杠杆"感觉"风险小 → 随意开仓 → 累积仓位 → 一次性爆

    闪卡073 第六部分：杠杆仓位

    合约中"后备95元"是假象的原因是什么？

    答案

    如果95元仍放在合约账户，它和5元保证金共担同一个强平线，实际上仍然是100元在承担风险；如果95元提出合约账户，资金效率极低，95元闲置的机会成本巨大。

    闪卡074 第七部分：体系认知

    Al Brooks体系解决的是哪两个变量？

    答案

    闪卡093 第十部分：补充知识

    止损纪律的重要性

    答案

    止损纪律是所有交易工具（现货/合约/期权）的核心变量。不设止损 = 本金可能全部亏损，甚至穿仓（合约）或被追缴保证金（卖期权）。

    闪卡094 第十部分：补充知识

    买权（Call/Put）的"有限风险"含义

    答案

    Call买方最大损失 = 已付权利金（价格归零也只亏这么多）；Put买方最大损失 = 已付权利金。无论标的价格如何变化，最大亏损就是购买时支付的权利金。

    闪卡095 第十部分：补充知识

    卖权（Short）的"无限风险"含义

    答案

    Short Put = 被行权需按约定价格接盘（若大跌，保证金被追缴）；Short Call = 被行权需按约定价格卖出（若大涨，保证金被追缴）；最大盈利 = 权利金，最大损失 = 理论无限（标的价格跌到0或涨到无穷）。

    闪卡096 第十部分：补充知识

    为什么买权是"彩票策略"？

    答案

    因为买权胜率低（30-40%），但盈亏比极高（可能10:1、20:1），像买彩票一样，用小额权利金去博取超额收益。

    闪卡097 第十部分：补充知识

    为什么卖权是"收割时间价值"？

    答案

    因为期权的时间价值会随到期日临近而衰减（Theta衰减），卖方在胜率高的方向收取权利金，等待时间价值慢慢消亡。

    闪卡098 第十部分：补充知识

    "顺势"的具体定义

    答案

    顺势 = 顺着当前趋势方向交易。强上升趋势中做多；强下降趋势中做空。不逆势，不猜顶底。

    闪卡099 第十部分：补充知识

    "逆势"的具体定义

    答案

    逆势 = 反着当前趋势方向交易。强上升趋势中做空（摸顶）；强下降趋势中做多（抄底）。Al Brooks不推荐，胜率低（25-35%）。

    答案

    通常结合多个周期： • 1H看短期趋势结构 • 4H看中期趋势方向 • 日线看长期趋势框架 具体周期选择取决于交易风格（短线/中线/长线）
