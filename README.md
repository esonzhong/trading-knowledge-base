# 交易知识库

这个仓库用于管理交易学习资料、闪卡、静态页面和后续工具。

## 当前内容

- `index.html`：总入口
- `flashcards/`：统一闪卡库
- `flashcards/decks/`：闪卡卡组数据
- `al-brooks-*.html`：原始页面和独立优化版页面

## 使用方式

本地直接打开：

```text
index.html
```

或进入：

```text
flashcards/index.html
```

## 版本管理建议

每完成一次内容整理或页面修改，就提交一个版本：

```text
git status
git add .
git commit -m "说明这次修改"
git push
```
